# Phase 4 · Incident inspection and replay

Incident workspaces show persisted evidence, confidence, agent latency bars, expandable structured decisions/tool outputs, highlighted patch lines, per-file change rationale, and approval controls. Replay scrubs recorded events and can play them sequentially without invoking models. Explicit simulation badges prevent confusion with actual verification.

The command palette and incident form trap keyboard focus, restore the opener's focus, and close on Escape. Responsive layouts support compact, tablet and desktop widths. Reduced-motion preferences disable transitions. UI typechecking and production compilation are required checks. These checks do not establish a WCAG AA audit; full assistive-technology testing remains outstanding.
